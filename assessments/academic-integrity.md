## 1. Collaboration matrix

| Instrument | Mode | Allowed | Not allowed |
|---|---|---|---|
| Weekly quizzes (formative) | Individual, open-notes after attempt | Discussing concepts after submission | Sharing answers before the review lecture |
| Graded quizzes (W04/W07/W10/W13 or W04/W12 — ⚠ reconcile) | Individual, closed-book | Formula sheet only | Any communication; any device with network access |
| Labs | Pairs where stated | Debugging together, discussing results | One partner writing while the other watches; submitting a partner's capture files you cannot explain |
| Subnetting problem set | Strictly individual | — | Any sharing of worked answers |
| Reliable-transport project | Pair | Joint design & code | Code from other pairs, the internet, or AI tools beyond §3 limits |
| Case-study write-ups (CS-01–03) | Individual | Citing the practice bank's *public reasoning* | Sharing drafts, trace annotations, or RCA reports |
| Capstone | Team of 3–4 | All team collaboration | Out-of-team code/design reuse without attribution |
| Exams | Individual, closed-book | Provided formula sheet | Everything else |

**Explainability rule** (applies to every collaborative instrument): each listed member
must be able to explain any submitted part on demand. Inability to explain is treated as
an integrity case, not a participation issue.

## 2. Evidence reproducibility rule

Any claimed measurement, capture, or output must be reproducible from submitted commands,
filters, and files. Fabricated or irreproducible evidence scores **zero on the whole
instrument** and triggers the formal integrity process. This is stricter than "plagiarism
of text" deliberately: this course's assessments are evidence-based, so evidence integrity
is the core of academic honesty here. Anchored in lab worksheets ("never claim a run you
did not perform") and the case bank's evidence-labeling discipline.

## 3. Generative AI use

⚠ VERIFY against the program's current AI policy — the split below is the course's
proposed default and is written to survive the likely policy families:

| Use | Verdict |
|---|---|
| Explaining compiler/tool errors in your own lab work | Permitted (cite the tool) |
| Grammar/clarity edits of your own prose | Permitted |
| Producing graded analysis text, case write-ups, exam answers | Not permitted |
| Generating project code you submit as your own design | Not permitted |
| Using AI to *understand* a protocol while studying | Permitted, same as any reference |

Students must include a one-line AI-use statement in every individual write-up: what tool
(if any) and for what. An absent statement defaults to "none used"; a false statement is
an integrity violation.

## 4. Exam conduct specifics (this course)

- Formula sheets are the only papers allowed besides the exam; they are provided — do not
  bring your own.
- Calculators: non-programmable only ⚠ VERIFY against university exam rules.
- Packet excerpts in exams are synthetic and self-contained (labeled as such in
  instructor keys); "I saw this in a real trace once" is not an answer channel — answers
  must come from the excerpt given.
- Seating plan and multiple-paper variants (A/B with reordered items) recommended where
  class size makes observation hard.

## 5. Attribution norms for technical writing

- Cite the standard/RFC/textbook when a claim rests on one (this course's reference
  discipline: the syllabus reading list and each lecture package's References section;
  standards-sensitive claims must trace to IEEE/RFC documents).
- Trace screenshots or pasted output must state capture date, tool, and filter.
- Reusing your own prior submission (self-plagiarism) across instruments is not allowed
  without instructor approval — e.g., a lab finding may be *referenced* in a case
  write-up but not resubmitted wholesale.

## 6. Process when a violation is suspected

1. Instructor gathers evidence (e.g., diff two submissions, irreproducible capture).
2. Confidential discussion with the student before any accusation is recorded.
3. Follow the **university's** formal process — the course does not run its own tribunal.
   ⚠ VERIFY the local process link and insert it here before publication.
4. Consistent with strategy §5: fabricated evidence = zero on the whole instrument as the
   *course-level* academic consequence, pending the university process outcome.
